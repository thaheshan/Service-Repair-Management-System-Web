# SRM Super Admin Portal

This is a separate dashboard for system administrators to manage onboarding requests and shop registrations.

## Getting Started

1. Navigate to this directory: `cd srm-admin-portal`
2. Install dependencies: `npm install`
3. Run the development server: `npm run dev`
4. Access the portal at: `http://localhost:3001`

## Features

- **Request Management**: View all pending registration requests with full details.
- **Approval Workflow**: Approve requests with a single click to generate activation tokens.
- **Shop Monitoring**: Track active shops and subscription statuses.
- **Role-Based Access**: Secured with the credentials provided above.
